# Imagen Reloaded

Respaldo del código fuente del sitio web de **Salón Imagen Reloaded**, desplegado mediante AppDeploy.

- Sitio: https://imagen-reloaded-dkgkwe.v2.appdeploy.ai/
- Stack: React 19 + TypeScript + Vite + Tailwind CSS
- Backend: AppDeploy SDK
- Administración: autenticación y allowlist de correo
- Contenido administrable: textos, servicios, galería, reseñas, ubicación y horarios

> Este repositorio contiene una copia del snapshot de código desplegado. Los datos persistidos en la base de datos de AppDeploy no forman parte del repositorio.
